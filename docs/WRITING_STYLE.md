# Documentation style

All documents in this repository use ASD-STE100 (Simplified Technical
English). The rules are in the shared
[writing style page](https://github.com/shallguard/spec/blob/master/WRITING_STYLE.md)
of the specification repository. That page applies to every repository of
the ShallGuard organization, so a change there reaches all of them.

The most important rules are:

- Write short sentences with one topic. Use the active voice and the
  present tense.
- Use "must" for a rule and "can" for a possibility. Do not use "should".
- Explain each technical term the first time you use it, or link to the
  [glossary](GLOSSARY.md).
- Use one word for one thing.

One exception applies. A requirement statement keeps its RFC 2119 form with
SHALL, SHALL NOT, or MAY, because ShallGuard needs that form.
